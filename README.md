One line, 83 characters — the funniest one-line out-of-office reply. An entry for make.fun's "Funniest One-Line Out-of-Office Reply" bounty ($2 in USDC).

> I'm away until Monday — I left my to-do list in charge and it has already resigned.

Why this line: a fresh turn on the usual away message — no beach, no inbox, no "limited access" cliché. The twist ("already resigned") is the last thing read, so the laugh arrives with the final word, and the line still reads like a real away message a person would gladly switch on.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) validates the line against the gate — UTF-8, 1–160 characters, not only whitespace, a single line — then writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies the written bytes.
